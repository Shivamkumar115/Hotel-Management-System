🏨 Hotel Management System

A desktop-based Hotel Management System developed using Java Swing, MySQL, and JDBC. This application provides a simple graphical interface for managing customers, rooms, bookings, and billing.

📌 Project Overview

The Hotel Management System is designed to simplify basic hotel operations through a user-friendly desktop application.

The project uses Java Swing for the graphical user interface, MySQL for database management, and JDBC for connecting the Java application with the MySQL database.

🚀 How to Run

1. Clone the Repository

git clone https://github.com/YOUR-USERNAME/Hotel-Management-System.git

2. Open the Project

Open the project in VS Code or another Java-supported IDE.

3. Setup MySQL

Create the database:

CREATE DATABASE hoteldb;

Create the required tables according to the project.

4. Configure Database Connection

Open the database connection file and configure:

MySQL username

MySQL password

Database name

JDBC connection settings

5. MySQL JDBC Connector

The project uses MySQL Connector/J for JDBC connectivity.

Make sure the JDBC connector is available in the project's classpath.

6. Run the Application

Run the login/main Java class to start the Hotel Management System.
